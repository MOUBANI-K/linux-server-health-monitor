# Linux Server Health Monitoring Automation

## Overview

A Python-based Linux server health monitoring script that checks
CPU usage, memory usage, disk usage, and system boot time.

The script generates alerts when system resource usage crosses
defined thresholds and stores health information in a log file.

## Features

- CPU usage monitoring
- Memory usage monitoring
- Disk usage monitoring
- System boot time monitoring
- High CPU usage alert
- High memory usage alert
- High disk usage alert
- Automated health logging

## Technologies Used

- Python 3
- Linux
- psutil
- Git
- GitHub
